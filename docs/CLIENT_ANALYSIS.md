## 1. Завдання в роботі (Фаза 3.1)

### 💬 1.1. Плашки повідомлень (Chat Bubbles)
- [ ] Оновити `ChatMessageTemplate`:
  - Додати виразну фонову плашку для повідомлень:
    - **Плашка Оповідача:** темний шляхетний фон `#161616`, тонка рамка `#262626`, скруглення `CornerRadius="8"`, внутрішні відступи `Padding="14,12"`.
    - **Плашка Гравця:** виразний синювато-вишневий або сталевий відтінок `#181B22` із рамкою `#2D3748`.
  - **Розміщення імені та часу:** блок імені та часу (`Оповідач: 00:22` або `Ти: 00:22`) розміщується у лівому верхньому кутку всередині самої плашки.
  - **Кнопка «Відкат» (↩️):** залишається **зовні плашки** праворуч угорі на загальному фоні вікна, як на затвердженому дизайн-макеті.
- [ ] Забезпечити можливість вільного виділення та копіювання тексту (через `SelectableTextBlock` або контекстне меню ПКМ).

### 🖱️ 1.2. Буфер обміну (ПКМ) в інпутах
- [ ] У контекстні меню головного інпуту `ChatInputEditor` та інпуту візарда `WizardInputBox` додати стандартні дії:
  - `Вставити (Ctrl+V)`;
  - `Копіювати (Ctrl+C)`;
  - `Вирізати (Ctrl+X)`;
  - Зберегти фірмовий стиль меню акаунта та функцію «Скасувати форматування».

### 🧭 1.3. Бічне меню та списки
- [ ] **Іконка кнопки виклику меню (☰):** замінити поточну стрілку-шеврон на акуратний векторний рівнобедрений трикутник `▲ / ▼ / ▶` (ідентичний до шеврона верхньої шторки персонажа), що обертається при відкритті/закритті панелі.
- [ ] **Закріплені кампанії:** повністю прибрати іконку канцелярської кнопки 📌 біля назви кампанії — закріплення позначається виключно фірмовою лівою вертикальною смужкою 3px `#7E0018`.

### 🎙️ 1.4. Голосове введення на кнопці відправки (Voice-to-Text)
- [ ] **Динамічна іконка кнопки:**
  - Якщо інпут порожній (`string.IsNullOrWhiteSpace(Text)`) — показувати іконку **Мікрофона** 🎙️;
  - Якщо в інпуті є введений текст — показувати іконку **Відправки** (стрілочка / паперовий літачок ➤).
- [ ] **Запис та розпізнавання аудіо:**
  - Реалізувати захоплення аудіо з мікрофона (затискання або клік-тогл із візуальною пульсацією);
  - Передавати записане аудіо на `POST /api/v1/voice/transcribe`;
  - Вставляти отриманий текст прямо в інпут для перегляду та редагування перед відправкою.

### 🧬 1.5. Динамічний рендер шаблону у шторці та прев'ю
- [ ] Реалізувати гнучкий компонент відображення (`DynamicSheetRenderer`):
  - Повністю виводити ВСІ поля, які існують у `_template.json` (включаючи травми, деталі зовнішності, титули, вік, здібності та довільні `custom_blocks`).
  - Архітектура компонента повинна автоматично відображати будь-які нові майбутні розділи та властивості користувацьких світів без зміни коду клієнта.
- [ ] **Кнопка ручної синхронізації в прев'ю (🔄):**
  - Додати кнопку оновлення драфту на основі ручних правок гравця в текстових полях прев'ю;
  - При натисканні відправляти драфт на `POST /api/v1/character/sync-draft` для гармонізації характеристик ШІ.
- [ ] **Кнопка завершення:** замінити текст `🚀 Створити персонажа` на строгий лаконічний `Завершити створення ➔`.
- [ ] **М'яке розсіювання (Fade Mask):** накласти `OpacityMask` із градієнтом зверху та знизу на `ScrollViewer` панелі Live Preview, усунувши різке обрізання вмісту при скролі.
