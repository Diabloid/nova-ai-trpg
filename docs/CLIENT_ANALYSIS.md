**Статус:** В роботі (Фаза 3.0)  
**Версія клієнту:** 1.4.0  
**Директорія:** `NovaTrpgClient/`

## 1. Завдання в роботі (Фаза 3.0)

### 🎛️ 1.1. Верхня шторка персонажа (Character Sheet)
- [ ] **Плавність:** Збільшити тривалість анімації розгортання шторки на ~0.2с (до `Duration="0:0:0.45"` із кривою `CubicEaseOut`).
- [ ] **Повна інформація з JSON:**
  - Додати відображення здібностей та заклять (`abilities` / `skills`) у вигляді окремого центрального блоку між екіпіруванням та рюкзаком;
  - Збалансувати ширину колонок: зменшити травми та екіпірування, зберегти достатній простір для рюкзака.
- [ ] **Фізичний відгук кнопки:** Додати ефект втоплення кнопки шторки на стан `:pressed` (`TranslateY="2"` або `Scale(0.97)` з плавним поверненням).
- [ ] **Автоскрол чату:** Усунути сповзання тексту чату вниз при відкритті шторки та при зміні розміру вікна — підписатися на подію зміни висоти/завершення анімації та викликати `ChatScroll.ScrollToEnd()`.

---

### 🧭 1.2. Бічне меню та кнопка виклику
- [ ] **Кнопка виклику меню (☰):**
  - Прив'язати кнопку виклику меню до краю: коли меню закрите — вона прикріплена до лівого краю екрана; коли відкрите — прикріплена до правого краю бічного меню;
  - Кнопка повинна бути завжди доступна (як у чаті гри, так і у вікні майстра Character Wizard).
- [ ] **Доступність під час створення героя:**
  - Бічне меню залишається доступним навіть під час відкритого візарда;
  - При спробі кліку на іншого героя або створення нового, коли візард незавершений — показувати модальне попередження: *"У вас є незбережений персонаж. Вийти без збереження? Так / Ні"*.
- [ ] **Стиль закріпленого чату:**
  - Прибрати червону заливку всієї картки кампанії;
  - Залишити стандартний темний фон `#141414`, а закріплення позначати виключно лівою вертикальною смужкою 3px кольору `#7E0018` та іконкою пін-шпильки.
- [ ] **Сортування кампаній:** Сортувати список кампаній у бічному меню за спаданням часу останнього повідомлення (найсвіжіші вгорі, закріплена — на вершині).
- [ ] **Плавність переносу тексту:** Усунути різке "тремтіння" літер при зміні ширини бічного меню (оптимізувати анімацію панелі та контейнера чату).

---

### 💬 1.3. Чат, Стрімінг, Анімації та Відкат ходу (Undo)
- [ ] **Уніфікація компонента чату:** Винести повідомлення у спільний `ChatMessageView` або єдиний `DataTemplate` для повторного використання в грі та у візарді.
- [ ] **Час повідомлень:** Додати відображення часу (наприклад, `21:14`) непомітним сірим 10px шрифтом біля кожного повідомлення.
- [ ] **М'яке розмиття зверху:** Додати `OpacityMask` із лінійним градієнтом прозорості у верхній край `ChatScrollViewer`, щоб повідомлення плавно танули в темряві при скролі.
- [ ] **Плавний темп стрімінгу:** Додати клієнтський буфер для відповідей Оповідача (послідовна плавна поява слів замість різкого викидання великих полотен тексту).
- [ ] **Fade-in анімація нових повідомлень:** Нові повідомлення плавно проявляються (`Opacity 0 -> 1`) зі зсувом знизу на 4–6px за ~0.18с.
- [ ] **Відкат ходу (Undo / 1 крок назад):**
  - На останньому блоці Оповідача відображати акуратну кнопку-іконку відкату (↩️);
  - При кліку: викликати `POST /api/v1/campaigns/{id}/rollback`, видаляти останнє повідомлення GM із чату та автоматично переносити текст попередньої дії гравця назад в інпут для редагування.

---

### ✍️ 1.4. Інпут, Синтаксис та Контекстне меню (ПКМ)
- [ ] **Синтаксис прямої мови:** Перевірити, що репліки починаються з тире `-` без обов'язкових закриваючих парних символів.
- [ ] **Парність для дій, думок та OOC:** Забарвлювати текст кольором дії `**...**`, думки `"..."` чи OOC `(...)` **лише після введення закриваючого символу**.
- [ ] **Скасування форматування через ПКМ:**
  - У контекстне меню інпуту додати пункт «Скасувати форматування»;
  - Дія екранує розмітку (перетворює на `\*\*...\*\*`), знімаючи колір та статус дії без фізичного видалення символів та тексту.
- [ ] **Стиль меню ПКМ:** Надати контекстному меню інпуту монолітний темний стиль з вишневими акцентами відповідно до дизайн-коду.
- [ ] **Приховування зірочок у візарді:** Очищати сирі символи `**` з тексту повідомлень Творця Долі перед виведенням на екран.
- [ ] **Підказка-тултіп:** Підсвітити назви команд до тире фірмовими кольорами відповідного синтаксису; додати hover-ефект на іконку `?`.
- [ ] **Колір фону інпуту:** Синхронізувати колір фону інпуту чату кампанії з кольором інпуту візарда.
- [ ] **Кнопка відправки:** Зробити м'який органічний ховер кнопки відправки в стилі кнопки «Створити нового персонажа».

---

### 🪟 1.5. Модальні вікна та Системні елементи
- [ ] **Модалка видалення персонажа:**
  - Прибрати заливку червоним кольором фону вікна (залишити темний нейтральний фон, червона тільки акцентна рамка);
  - Замінити написи кнопок на лаконічні «Так» та «Ні»;
  - Прибрати емодзі смітника `🗑️`.
- [ ] **Кнопки скасування:** У модалці редагування героя, модалці видалення героя та у вікні Character Wizard стилізувати кнопки «Скасувати» в єдиний спокійний темно-смарагдовий/зелений стиль замість червоного/сірого.
- [ ] **Редагування персонажа:** Збільшити `MaxHeight` текстових полів у модалці редагування та додати динамічний скрол.
- [ ] **Перетягування вікна:** Реалізувати перетягування вікна за шапку у віконному режимі через обробник `PointerPressed` (`BeginMoveDrag(e)`).
- [ ] **Системні кнопки вікна (CaptionButtons):** Налаштувати благородний стриманий темно-вишневий hover для кнопки закриття та темний сіро-бордовий hover для кнопок мінімізації/розгортання.
- [ ] **Прев'ю у візарді:** Зробити однакові відступи зліва та справа, усунувши несиметричність за рахунок накладеного або резервного скролбара.
