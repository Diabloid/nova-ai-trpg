## 1. Завдання в роботі (Фаза 2)

### 🎨 1.1. Полірування інтерфейсу та системних контролів
- [x] **Кастомні стилі системних кнопок вікна (CaptionButtons):**
  - Плавне графітове затемнення при `pointerover` для кнопок згортання та розгортання;
  - М'який темно-бордовий градієнтний hover для кнопки закриття вікна (замість стандартного різкого світло-сірого прямокутника Fluent-теми).
- [x] **Реакція головного поля вводу (ChatInputEditor):**
  - Додати для `Border.inputBox` плавний стиль `:pointerover` (підсвічування рамки м'яким відтінком `#444444`);
  - Колір фокусу `#5A0010` **не змінювати** (він відповідає кнопці відправки).

### 🎒 1.2. Інвентар: Інтерактивні плашки контейнерів (Expander)
- [x] Обгорнути кожен контейнер у висувній шторці персонажа в стилізований `Expander` (за замовчуванням згорнуто).
- [x] Запам'ятовувати стан розгорнутих контейнерів у локальний конфіг між перезапусками програми.

### 👥 1.3. Редизайн бічного меню (SplitView) — Ієрархія: Персонажі ➔ Кампанії
- [x] **Верхній блок дій:**
  - Кнопка «➕ Створити нового персонажа».
- [x] **Секція персонажів (Список героїв):**
  - Відображати картку героя (аватарка, ім'я, архетип).
  - В один ряд праворуч від імені розмістити компактні інтуїтивні іконки дій із ToolTip:
    • ✏ `[Редагувати заготовку]` (відкриває вікно редагування опису/імені);
    • 🗑 `[Видалити персонажа]` (із модальним підтвердженням).
- [x] **Секція Кампаній обраного персонажа:**
  - При виборі персонажа нижче розкривається список його кампаній (будь-яка кількість паралельних історій).
  - Кнопка **«➕ Нова Кампанія»** — створення нової пригоди за цього героя (одразу генерується та показується вступний пост Оповідача).
  - Елемент кампанії у списку містить:
    • Назву кампанії та поточну локацію;
    • 📌 `[Закріпити кампанію]` (закріплені кампанії піднімаються нагору списку);
    • 🗑 `[Видалити кампанію]` (видалення конкретного чату).
- [x] **Повна історія повідомлень у чаті:**
  - При перемиканні між кампаніями в чат завантажується **вся історія діалогу** (як у Telegram), без обрізань, з автоскролом до останньої репліки.
- [x] **Картка акаунта в самому низу бічного меню:**
  - Завжди закріплена внизу: аватарка, ім'я користувача, email та статус підписки: **"Без підписки"**.
  - При кліку вгору випливає контекстне меню (Flyout):
    • «⚙ Налаштування»;
    • «🚪 Вийти з акаунту» (функція логауту без закриття застосунку).
- [x] Видалити стару кнопку «Лист персонажа» з бічного меню.

### 🧙‍♂️ 1.4. Екран створення персонажа (Character Wizard)
- [x] Вікно або режим співтворчості з Творцем Долі (AI).
- [x] Попередній перегляд сформованого листа персонажа.
- [x] Кнопка підтвердження створює заготовку героя та автоматично пропонує розпочати першу Кампанію зі вступним постом Оповідача.
