## 1. Завдання в роботі (Фаза 3.2: UX та стабілізація)

### ✍️ 1.1. Розумний фолбек синтаксису (Default Action) у `IntentParserService.cs`
- [x] **Опціональний синтаксис дій для голосового та швидкого вводу:**
  - Якщо введений текст не містить жодного спецсимволу (`**`, `"`, `-`, `()`), тобто `intents.Count == 0`:
    - Автоматично додавати токен `action: rawAction.Trim()`.
    - Гравець більше **не зобов'язаний** вручну виставляти `**` при надиктовуванні дій голосом або звичайному друці в інпуті!
  - Якщо текст містить явну розмітку (`**`, `"`, `-`, `()`), парсер зберігає точне розділення на `action`, `thought`, `speech`, `ooc`.

### 📐 1.2. Виправлення геометрії плашки коротких реплік (`MainWindow.axaml`)
- [x] **Усунення сходинки та перепаду кутів на коротких повідомленнях:**
  - Для `Border.chatBubbleBody` (у стилях та шаблоні `ChatMessageTemplate`) додати `MinWidth="140"`.
  - Забезпечити, щоб тіло повідомлення завжди гарантовано було ширшим за верхнє вушко (`Ти: HH:mm` ~115px), усуваючи злам рамки на репліках на кшталт «Я в ахуї», «Так», «Ні».

### 🌫️ 1.3. Симетричне розсіювання чату (Fade Mask) зверху та знизу (`MainWindow.axaml`)
- [x] **Оновлення `OpacityMask` для `ChatScroll` та `WizardScroll`:**
  - Замінити односторонній піксельний градієнт `0,0 -> 0,16` на симетричний вертикальний відсотковий градієнт `StartPoint="0%,0%" EndPoint="0%,100%"`:
    - `0.00..0.02`: плавне розсіювання зверху під шапкою;
    - `0.02..0.98`: 100% непрозорий контент чату;
    - `0.98..1.00`: плавне розсіювання знизу над полем вводу (аналогічно реалізованому у прев'ю візарда).

### ⏳ 1.4. Тимчасові (ефемерні) системні повідомлення («Система:»)
- [x] **Автозникнення службових попереджень:**
  - Усі системні сповіщення (`Sender = "Система:"`, технічні помилки зв'язку, ліміти ШІ):
    - Додавати з прапорцем `IsSystem = true`;
    - Запускати фоновий таймер на **10–12 секунд**, після чого автоматично і безслідно видаляти це повідомлення з `ChatMessages` або `WizardMessages`.
  - **Виключення з історії кампанії:** Гарантувати, що повідомлення із `Sender = "Система:"` (або `IsSystem == true`) ніколи не серіалізуються у файл історії гри при завантаженні/збереженні.

### 🛑 1.5. CancellationToken для скасування генерації ШІ у візарді (`MainWindowViewModel.cs`)
- [x] **Миттєве зупинення запитів при виході з візарда:**
  - Додати поле `CancellationTokenSource? _wizardCts` у `MainWindowViewModel`.
  - При виклику `SendWizardMessageAsync`, `FinalizeAndStartGameAsync` та `SyncDraftAsync` створювати новий токен та передавати його в API-сервіс;
  - При виклику `CancelCharacterCreation()` викликати `_wizardCts?.Cancel()`, скидати `IsWizardTyping = false` та очищати стан очікування, щоб запит до бекенду миттєво обривався, а ШІ не крутив генерацію даремно.
