## 1. Підсумки виконання попередніх етапів (Звіт про реалізацію)

Усі ключові архітектурні та UI/UX проблеми з первинного аудиту повністю вирішено:

- [x] **Чиста архітектура MVVM & Сервісний шар:**
  - Впроваджено `Microsoft.Extensions.DependencyInjection` та `IHttpClientFactory` у `App.axaml.cs`.
  - Створено інтерфейси та сервіси (`Services/`): `IGameApiService`, `IIntentParserService`, `ITextSanitizerService`.
  - Монолітний `MainWindowViewModel` розвантажено від низькорівневої мережевої та парсинг-логіки.
- [x] **Міграція на `System.Text.Json`:**
  - Повністю прибрано застарілий `Newtonsoft.Json`. Весь транспорт і DTO серіалізуються через високопродуктивний вбудований рушій .NET 10.
- [x] **Конфігурація без хардкоду (`appsettings.json`):**
  - Базова адреса сервера (`BaseUrl`) та таймаути винесені в зовнішній конфіг `appsettings.json`.
- [x] **Синхронізація DTO (Контракт v1.1.0):**
  - Моделі оновлено під багаті об'єкти стану: `ItemInfo { Name, Desc }`, `AbilityInfo`, `Injury { Location, Type }`, `SessionInfo`.
  - Повністю усунено помилки десеріалізації та "милиці" з `dynamic`.
- [x] **Інтерактивна верхня шторка стану (Top Drawer):**
  - Верхня смуга лаконічна: Ім'я, Локація та Загальний стан здоров'я.
  - При кліку на неї плавно виїжджає детальна панель із травмами (з кольоровими бейджами), екіпіруванням та деревом контейнерів інвентарю.
- [x] **Мультисесійність у бічному меню (SplitView):**
  - Бічне меню оживлено: гравець може переглядати збережені сесії, вводити нову назву сесії та перемикатися на льоту.
- [x] **Справжній стрімінг (SSE Client):**
  - Метод `StreamActionAsync` реалізує потік `IAsyncEnumerable<SseEvent>`, відображаючи символи розповіді Оповідача в реальному часі без штучних затримок `Task.Delay`.
- [x] **Захист від подвійних запитів:**
  - Введення та кнопка відправки автоматично блокуються під час генерації ходу завдяки `[RelayCommand]` та `IsEnabled="{Binding !IsTyping}"`.

## 2. Дорожня карта наступного етапу: Roadmap 2.0 (UI/UX, Геймплей, Аудіо)

### 🎨 Фаза 5. Rich Text / Markdown у повідомленнях Оповідача
- [ ] **Підтримка форматування в чаті:**
  - Інтеграція відображення жирного тексту, курсиву, цитат та прямої мови персонажів у репліках чату (Avalonia Markdown або кастомні стилізовані `TextBlock`/`Run`).
  - Візуальне підсвічування системних повідомлень та результатів дій.

### 🎲 Фаза 6. Візуалізація перевірок та Кидка кісток (Dice Roll Widget)
- [ ] **Віджет перевірки складності (D20 Animation):**

  - Відображення типу складності: "Критичний успіх", "Успіх", "Провал".

### 📜 Фаза 7. Вкладка «Журнал пригод та Квести»
- [ ] **Розширення меню / бічної панелі:**
