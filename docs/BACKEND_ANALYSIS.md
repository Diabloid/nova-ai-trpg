## 1. Завдання в роботі (Фаза 3.2: Голосове розпізнавання та STT)

### 🎙️ 1.1. Інтеграція надшвидкого Groq Whisper STT (`core/services/voice_service.py`)
- [x] **Підтримка `GROQ_API_KEY` в оточенні:**
  - Зчитувати `GROQ_API_KEY` з `os.getenv("GROQ_API_KEY")`;
  - Додати параметр-зразок `GROQ_API_KEY=gsk_...` у `Backend_Python/.env.example`.
- [x] **Виклик OpenAI-сумісного Audio Transcription API Groq:**
  - Якщо `GROQ_API_KEY` наявний:
    - Відправляти аудіофайл на `https://api.groq.com/openai/v1/audio/transcriptions` з моделлю `whisper-large-v3-turbo` (або `whisper-large-v3`) через `httpx.AsyncClient(timeout=15.0)`;
    - Передавати `language="uk"`, `temperature=0.0`, заголовок `Authorization: Bearer {GROQ_API_KEY}`;
    - Парсити відповідь `{"text": "..."}` та повертати розпізнаний текст (латентність 0.3–0.5 с).

### ⚡ 1.2. Оптимізація та захист від обривів у резервному Odirouter STT

  - Вилучити недоступну модель `free-gemini-2.5-flash` (повертає помилку 403 Forbidden).

  - Замінити на чітку інструкцію: *«Транскрибуй максимально повно та точно всі вимовлені гравцем слова українською мовою. Якщо слів взагалі немає, поверни порожній рядок»*.
- [x] **Каскадна стійкість:**
