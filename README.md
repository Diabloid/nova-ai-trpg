# NOVA AI TRPG

**NOVA AI TRPG** — десктопна текстова рольова гра (TRPG) з мультіагентним AI Game Master у власному фентезі-сеттингу.

Проєкт побудований за клієнт-серверною архітектурою: локальний десктопний клієнт на **Electron + React + TypeScript** взаємодіє з **FastAPI**-сервером на **Python** через REST API.

---

## Архітектура та технологічний стек

### Ігровий пайплайн
Обробка кожного ходу в грі відбувається суворо послідовно:

```text
Гравець (дія / репліка / думка / OOC)
   │
   ▼
Оповідач (AI Game Master) — генерує художню відповідь світу та NPC
   │
   ▼
Аналізатор стану — виділяє зміни HP, локації, інвентаря та характеристик
   │
   ▼
Стан кампанії — атомарне оновлення та збереження слота гри
```

### Стек технологій

- **Desktop Client (`client_electron/`)**:
  - **Electron** (`^45.3.1`)
  - **React** (`^19.3.1`) + **TypeScript** (`~7.0.2`)
  - **Vite** (`^8.3.6`) + `vite-plugin-electron`
  - **Tailwind CSS v4** (`^4.3.5`)
  - **Zustand** (`^5.1.0`) для керування станом
  - **Lucide React** для іконок
  - **Oxlint** для лінтингу

- **Backend API (`Backend_Python/`)**:
  - **Python** + **FastAPI** (`0.141.1`) + **Uvicorn** (`0.53.0`)
  - **Pydantic v2** (`2.13.5`) для схем і валідації даних
  - **OpenAI Python SDK** (`3.19.2`) + `httpx` для роботи з LLM-провайдерами
  - **Python-dotenv** (`1.2.3`) для змінних середовища
  - Файлове JSON-сховище персонажів, лору та збережень кампаній

## Основні можливості

- **Конструктор персонажа (Wizard)** — покрокове створення героя: ім'я, вік, стать, раса, клас, світогляд, розподіл характеристик або вибір готових пресетів.
- **Кампанії та слоти збережень** — керування кампаніями, створення нових ігор, завантаження збережень, відкат або перегенерація останнього ходу.
- **Наративний чат із NOVA-синтаксисом** — візуальне підсвічування й семантичний розбір введення гравця:
  - `**Дія**` — фізичні дії персонажа
  - `"Думка"` — внутрішній голос / монолог
  - `- Репліка` — пряма мова
  - `(OOC)` — позаігрове звернення до ШІ
  - Звичайний текст за замовчуванням сприймається як дія
- **Голосові функції** — окремий API-модуль (`voice`) для роботи з голосом.
- **Інспектори стану та лору** — відстеження характеристик, інвентаря, активних ефектів та ігрової енциклопедії прямо в інтерфейсі клієнта.

## Структура репозиторію

```text
nova-ai-trpg/
├── Backend_Python/           # FastAPI бекенд та логіка AI-агентів
│   ├── core/                 # Оркестрація пайплайну, LLM-клієнти, робота зі станом
│   ├── routers/              # Ендпоінти: characters, wizard, campaigns, gameplay, voice, legacy
│   ├── schemas/              # Pydantic-моделі запитів та відповідей
│   ├── data/                 # Лор світу, промпти, конфіги, збереження та персонажі
│   ├── main.py               # Точка входу FastAPI-застосунку
│   ├── dependencies.py       # DI-залежності серверних модулів
│   ├── requirements.txt      # Залежності Python
│   └── .env.example          # Шаблон змінних середовища (API-ключі)
│
└── client_electron/          # Десктопний клієнт Electron + React
    ├── electron/             # Головний процес Electron та preload-скрипти
    ├── src/                  # React-інтерфейс, Zustand-стори, компоненти, утиліти
    ├── index.html
    ├── package.json
    └── vite.config.ts
```

## Локальний запуск

### 1. Вимоги
- **Python 3.11+**
- **Node.js 20+** та **npm**

### 2. Налаштування та запуск Backend (`Backend_Python/`)

```bash
cd Backend_Python

# Створення та активація віртуального середовища (Windows PowerShell)
python -m venv venv
.\venv\Scripts\Activate.ps1

# Встановлення залежностей
pip install -r requirements.txt

# Налаштування змінних середовища
copy .env.example .env
```

Заповніть потрібні API-ключі у `Backend_Python/.env`:
- `ODIROUTER_API_KEY`
- `VYCE_API_KEY`
- `DAHL_API_KEY`
- `GROQ_API_KEY`

Запустіть сервер (за замовчуванням слухає `http://127.0.0.1:8000`):

```bash
python main.py
```

Після запуску інтерактивна документація Swagger буде доступна на `http://127.0.0.1:8000/docs`.

### 3. Налаштування та запуск Desktop Client (`client_electron/`)

```bash
cd client_electron

# Встановлення пакетів
npm install

# Запуск у режимі розробки (Vite + Electron)
npm run dev
```

Додаткові скрипти:

```bash
# Перевірка типів і продакшн-збірка
npm run build

# Лінтинг коду (oxlint)
npm run lint
```
